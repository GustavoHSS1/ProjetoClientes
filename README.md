# ProjetoClientes

Projeto acadêmico desenvolvido por **Gustavo Henrique de Souza Silva** e **Maria Clara de França e Silva**, com foco em gestão/cadastro de clientes.

## 📋 Sobre o projeto

O ProjetoClientes é uma aplicação web dividida em duas partes principais:

- **Frontend**: interface para interação com o usuário, construída em TypeScript com estilização em SCSS
- **Backend**: camada responsável pela lógica da aplicação e fornecimento de dados para o frontend

Um vídeo de demonstração do projeto está disponível em: **[youtu.be/zqkuytGorQE](https://youtu.be/zqkuytGorQE)**

## 🛠️ Tecnologias utilizadas

- **TypeScript** — linguagem principal do projeto
- **SCSS** — pré-processador de CSS para estilização
- **HTML** — estrutura das páginas

## 📁 Estrutura do projeto

```
ProjetoClientes/
├── backend/    # Código do servidor / lógica de negócio
├── frontend/   # Interface e experiência do usuário
└── README.md
```

## 🚀 Como executar o projeto

> As instruções abaixo são um ponto de partida geral — ajuste conforme as dependências específicas de cada parte do projeto.

1. Clone este repositório:
   ```bash
   git clone https://github.com/GustavoHSS1/ProjetoClientes.git
   ```
2. Acesse a pasta do **backend** e instale as dependências:
   ```bash
   cd ProjetoClientes/backend
   npm install
   npm start
   ```
3. Em outro terminal, acesse a pasta do **frontend** e instale as dependências:
   ```bash
   cd ProjetoClientes/frontend
   npm install
   npm start
   ```
